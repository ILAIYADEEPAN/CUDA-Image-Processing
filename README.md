# CUDA Image Processing Project

## Features
- GPU accelerated processing
- Batch image processing
- Edge detection
- Gaussian blur
- Performance comparison

## Technologies
- CUDA
- OpenCV
- C++

## How to Run
1. Install CUDA Toolkit
2. Install OpenCV with CUDA
3. Build using CMake
4. Run executable

## Results
GPU processing was significantly faster than CPU processing for large image datasets.
